# Рабочие материалы Baibol Online

Репозиторий рабочих досок проекта «Байбол Онлайн». Страница локаторов Appium находится в `index.html`.
Публикация GitHub Pages идёт из корня ветки `main`.

- Репозиторий — https://github.com/Robilko/baibol-online-work.
- Опубликованная страница — https://robilko.github.io/baibol-online-work/.
- Локальная папка приложения — соседний репозиторий `../baibol-online`.
- При изменении локаторов в приложении следуй разделу «Страница локаторов Appium» в его `AGENTS.md`.
- В этой странице сохраняй поиск, фильтры, копирование локаторов и существующие разделы.
- Перед отправкой изменений проверь HTML, работу затронутых элементов страницы и отсутствие секретов.
- После публикации проверь страницу на GitHub Pages.
- Сохраняй относительные ссылки между материалами, чтобы репозиторий можно было перенести в GitLab.
